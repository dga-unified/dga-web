# dga リリースノート

「ディアボロの大冒険」を Godot で遊べるように作り直した個人制作のファンプロジェクトです。

---

## v0.2.4

### 変更
- 配布ファイルを小さくするため、BGM の音質を下げ、モノラルにしました。
- Windows 版は、BGM を exe の外の `bgm` フォルダに分けました。zip をすべて展開してから起動してください。`bgm` の中のファイルを置き換えると、曲を差し替えられます。
- Windows 版の zip に、説明（README.txt）とリリースノートを入れました。
- 敵が時を止めている間の移動を、1 マスずつ見せるようにしました。
- 罠と凍結のターンの待ち・音・台詞・▼を、原作の順にそろえました。
- 攻撃を受けるときや、射撃・投げが当たるときの演出を、原作に近づけました。

### 修正（不具合）
- 敵が時を止めている間に力尽きると、攻撃が表示されないまま終わる不具合を修正。
- スティックを反対へ倒したときなどに、方向が押されたままになる不具合を修正。
- 方向キーの長押しを離したあと、1 歩余分に歩く不具合を修正。
- 無線機・魂のコイン・ｸﾞｯﾁのﾊﾞｯｸﾞの説明を開くとエラーになる不具合を修正。
- スマートフォンの縦持ちで、持ち物の長い名前や説明欄がはみ出す不具合を修正。
- 中断セーブから再開すると、一部の状態が引き継がれない不具合を修正。
- ダンジョンを出入りするたびに、使用メモリが増える不具合を修正。

### 既知の問題
- 特になし。

## v0.2.2

### 追加
- **倉庫番**: 亀の部屋の奥にｽﾋﾟｰﾄﾞﾜｺﾞﾝが現れるようになりました（ホテルの外を制覇すると現れます）。床の倉庫とは別の倉庫で、アイテムを預ける・引き出す・処分するができます。
  - 預けられる数は、亀の成長に合わせて 50・100・150・200・300 個に増えます。
  - 持ち物の画面で印（✓）を付けて、まとめて選べます。上のタブで種類を絞り込めます。
  - 射撃DISCは預けるとまとまります（1 つ 99 発まで）。引き出すときは本数を選べます。
  - 処分すると、値段のぶん亀が成長します。直前の 1 回は取り戻せます。
- 持ち物の一覧にアイテムの絵を表示します。識別済みの装備DISCはスタンドの絵になり、鑑定済み・識別済みならスロット数（空き/総数）も出ます。
- 入れ物のヤバイものは、容量を表示します（残り/総容量。ホルマジオのビンは未識別だと残りの容量だけ）。

### 変更
- 設定の窓と倉庫番の画面のタブは、Q・E（ゲームパッドは L・R・ZL・ZR）で切り替えるようにしました。キー設定で変更できます。設定の窓には、いまの割り当てでの切り替え方を表示します。
- 亀の中で物を拾う・置く・乗ったときの一言は、ボタンを押さなくても消え、歩きや操作を止めなくなりました。
- 亀のジッパーに射撃DISCを捨てたときの値段は、弾数×50 にしています。
- 鉄獄・裏鉄獄を原作に合わせました。
  - 射撃DISCの代わりに、床にも店にもカエルが出ます。
  - DISCケースとタイヤの中身は、装備DISC 20%・記憶DISC 80% です。
  - 床の DISCケース・DIOの骨・コミックスは、消し炭にならなくなりました。
- ボス日記を消すと「全要素解除」が OFF に戻り、次の冒険でもう一度確認します。

### 修正（不具合）
- ｺﾋﾟｰ人形が隣のプレイヤーを殴る不具合を修正。
- 移動を封じられたｺﾋﾟｰ人形が歩き回る不具合を修正。
- 敵に殴られて吹き飛ぶときの音・メッセージ・間の順番を原作に合わせました。
- ﾄﾘｯｼｭに柔らかくされて弾むときの命中音・台詞・間の順番を原作に合わせました。
- 持ち物の画面の操作の手引きが、画面の下で切れる不具合を修正。

### 既知の問題
- 台詞送りの間、敵の移動や攻撃の絵の進み方がそろわないことがあります（DIO の時止め中など）。
- 一部の曲（+α・0.16 の追加曲の一部）は、まだ収録していません。
- スマホの縦持ち・横持ちでは、一部の画面の項目が小さく、押しにくいことがあります。
- 帝王再臨はホテルの外（通常の冒険）では使えません。仲間にできる確率などのバランスは調整中です。
- 0.14 / 0.15 相当のプリセットは完成途上で、一部の要素が未対応です。

## v0.2.0

### 追加
- **帝王再臨**: 敵を仲間にして連れていくモードを追加（レクイエムの迷宮・ディアボロの試練）。ホテルの扉で「帝王として再臨する」を選ぶと始まります。
- 仲間にした敵は、階段でもついてきて、中断セーブからも復元されます。経験値を得て成長し、レベルの上限は原則 99 です。
- 仲間への作戦（命令）: 追従・攻撃・撤退などをプリセットから選べ、特技を使うかどうかも指定できます。メニューから命令を外すこともできます。
- 仲間の預かり所: パソコンから仲間を預けたり引き出したりできます。入場時に連れていけない仲間は預かり所へ回ります。
- 仲間の特技: 射撃・状態異常・ミステリーアタック・時止め・治療など、敵が使っていた特技を仲間も使えるようになりました。敵が仲間を標的にする特技も増えています。
- 移動の特性: 壁抜け・壁を食う・水へ入る敵などの移動が、仲間・敵の双方で働きます。
- 仲間と敵の殴り合い・特技に専用の演出（攻撃の構え、のけぞり、点滅して消える、弾の当たるタイミングに合わせた音と台詞）を追加。
- 画面表示: 仲間の頭上の印（ハートの点滅など）、状態画面の仲間一覧（名前・Lv・作戦名）、主画面メニューの 2 列配置。
- 仲間になる瞬間の専用効果音。
- 0.14 / 0.15 相当のプリセット（0.15 は日付つきの複数版）を、また選べるようにしました（完成途上のため、一部の要素は未対応です）。
- **Android 版（APK）と Web 版の公開を始めました。** 今後は Windows・Android・Web を同じ版で出します。
- Android: 縦持ち・横持ちに合わせたレイアウト、仮想パッド（十字の 8 方向化、大きさ・透明度の設定、射撃・便利ショートカット）、窓の寸法の見直し。
- Web 版: PWA 対応、更新通知、MIDI による BGM 再生、音声の復帰処理。
- オプションに「履歴」、表示に「ボタン配置」、メニューの大きさ（小・中・大）、全体マップの表示位置の切り替えを追加。
- バランス確認用の自動プレイボットの強化（作戦の学習・先読み探索など）。

### 変更
- オプションの初期値を変えました（新しく始める場合。すでに保存した設定はそのままです）: 仲間の HP% 表示・仲間への命令・経験値ゲージ・店での売値表示・ペリーコロの回収品・時止め音のアニメ化・グリッド表示を ON、仲間のターンごと回復を 1%、満腹度表示をゲージ付きにしました。
- 「時止めの効果音を今風に」を「時止め音のアニメ化」に改名しました。
- タイトルのメインメニューの窓が、項目数に合わせて詰まるようにしました。
- 経験値の知らせを「ディアボロは4の経験値を手に入れた」の 1 行にそろえました。
- 敵が殴る・殴られる文や被ダメージの行を 1 行にまとめ、絵の演出のあとに出します。
- 眠り・凍結・痺れなど動けない間、ドッピオ交代、仗助の暴れを、画面が 1 ターンずつ進めて見せます。
- 帝王再臨のダメージ計算をトルネコ3 に合わせ、仲間の経験値の縮尺・成長も同様にしました。
- 台詞の窓や選択肢の窓が画面の幅いっぱいに出ないよう整理し、スマホの小さい文字を大きくしました。
- ダッシュにブレーキを追加。罠を踏んだ絵の間は操作を受け付けません。
- 帝王再臨と通常の攻略は完全に別の進行として扱います。

### 修正（不具合）
- 敵が壁抜け・水渡りなどをするときに仲間と位置が食い違う不具合を修正。
- 眠りなどで動けない敵の動きの過程が一気に飛んで見える不具合を修正。
- 敵の弾が当たった音が早すぎる、倒れた敵が弾の飛ぶ前に消える不具合を修正。
- ｽﾃｨｯｷｰ･ﾌｨﾝｶﾞｰｽﾞが 1 マス先の敵に届いたとき、被弾や消える演出が出ない不具合を修正。
- 倒した敵の落とし物が、敵が消える前に床に出る不具合を修正。
- 記憶DISC・射撃DISC・コミックスなどの絵が、版によって水色の四角や透明になる不具合を修正。
- 0.16 の装備枠で、原作の表にないスタンドの絵が汎用の絵になる不具合を修正。
- 呪われた装備 DISC の印が詳細の窓などに出ない不具合を修正。
- 引き継いだ倉庫の物が壁のマスに置かれる不具合を修正。
- 亀の中・ホテルでｴﾆｸﾞﾏの紙へ入れる操作や、物を拾ったときの一言が正しく動かない不具合を修正。
- 中断セーブした仲間の欄が復元されない不具合を修正。
- Android: 設定窓・識別帳・記録窓・持ち物メニューの表示崩れ、タッチ操作が効かない不具合を修正。
- Web: 音が出ない、記録の保存まわりが不安定になる問題を修正。
- テスト・ログ整理などの内部的な修正を多数行いました。

### 既知の問題・今後
- 帝王再臨はホテルの外（通常の冒険）では使えません。今後の対応を検討中です。
- 仲間にできる確率（勧誘率）などのバランスは調整中です。
- 勧誘・レベルアップのキラキラ演出は見直し中のため、既定では出ません。
- 0.14 / 0.15 相当のプリセットは完成途上で、一部の要素が未対応です。
